# WhatsApp Web Clone (Green API)

Клон веб-версии WhatsApp с использованием React и [Green API](https://green-api.com/). Проект реализует отправку и получение сообщений в реальном времени, оптимистичный UI и работу с реальными номерами телефонов.

## 🚀 Возможности

- **Авторизация:** Вход по ключам `apiUrl`, `idInstance` и `apiTokenInstance` от Green API.
- **Чаты:** Просмотр списка активных диалогов и создание новых (с умной валидацией номеров через `libphonenumber-js`).
- **Сообщения:** Отправка сообщений, получение входящих и исходящих через Polling.
- **Оптимистичный UI:** Мгновенное отображение отправленных сообщений с последующей синхронизацией ID с сервером.

## 🛠 Стек технологий

- **Фреймворк:** React 18 + TypeScript (Vite)
- **Роутинг:** React Router v6
- **Управление состоянием:** Zustand
- **Работа с API / Кэширование:** TanStack Query (React Query)
- **Стилизация:** Tailwind CSS
- **Иконки:** Lucide React

## 📋 Требования

Для запуска проекта вам потребуются:
- **Node.js** (версия 18.x или выше)
- **Yarn** (пакетный менеджер)
- Аккаунт в [Green API](https://green-api.com/) (созданный инстанс с отсканированным QR-кодом WhatsApp).

## 💻 Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/qb1ty/green-chat или git clone git@github.com:qb1ty/green-chat.git
   cd green-chat
   ```

2. **Установите зависимости с помощью Yarn:**
   ```bash
   yarn install
   ```

3. **Запустите сервер для разработки:**
   ```bash
   yarn dev
   ```

4. **Откройте приложение:**
   Перейдите в браузере по адресу `http://localhost:5173`.

## 🔑 Инструкция по использованию

1. Зарегистрируйтесь на сайте [Green API](https://green-api.com/) и создайте инстанс (Instance).
2. В личном кабинете Green API отсканируйте QR-код через ваше приложение WhatsApp на телефоне (Связанные устройства).
3. **Важно:** В настройках инстанса перейдите в раздел "Уведомления" и обязательно включите получение уведомлений (Receive notifications). Убедитесь, что отмечены типы вебхуков для входящих и исходящих сообщений, иначе поллинг в приложении не сможет получать новые данные.
4. Скопируйте ваши учетные данные из консоли Green API:
   - `API URL` (например, `https://7103.api.green-api.com`)
   - `ID Instance`
   - `API Token Instance`
5. Вставьте эти данные на странице входа в запущенном приложении.
6. Для создания нового диалога введите номер телефона получателя, начиная с кода страны (например: `+7 777 123 45 67`), и нажмите "Создать чат".
